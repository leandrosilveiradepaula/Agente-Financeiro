# v2.2.31 — TEST error traceability and persistence

## Scope

This release consolidates error traceability and persistence in:

- `TEST - Agente SQL Financeiro DuckLake - v2.2.31`

The PROD workflow was not changed.

## Implemented changes

### Question validation errors

`Code - Resposta Erro Pergunta` now returns a stable error contract with:

- `run_id`
- `request_id`
- source and environment
- user and authentication context
- `run_context`
- `rastreabilidade`
- deterministic error classification

Validated classifications:

- `QUESTION_EMPTY`
- `DESTRUCTIVE_OPERATION_BLOCKED`
- `MASS_DATA_EXTRACTION_BLOCKED`
- `SENSITIVE_OBJECT_ACCESS_BLOCKED`

Node contract version:

- `v2.2.44-question-error-classification-safe`

### Generated SQL, repair and preflight errors

`Code - Resposta Erro SQL DuckLake` preserves:

- offline validation diagnostics
- repair attempts and diagnostics
- Watson/DuckLake preflight diagnostics
- terminal error classification
- full execution traceability

Node contract version:

- `v2.2.43-sql-error-traceability`

### Received SQL errors

`Code - Resposta Erro SQL Recebida` now uses the same traceability contract for SQL supplied directly for execution.

Node contract version:

- `v2.2.46-received-sql-error-traceability`

### Shared error persistence

All three error paths write to the existing table:

- `public.ai_generated_query_log`

Shared nodes:

- `Code - Montar SQL Log Erro DuckLake`
- `Postgres - Gravar Log Erro DuckLake`

Persistence contract version:

- `v2.2.45-error-log-persistence`

No database schema migration was required in this phase.

## Security note

The exact n8n export contained literal Gemini and IBM Watson Orchestrate API keys.

Therefore:

- the exact source export must not be committed;
- the repository package contains only the sanitized export;
- n8n credential IDs were removed from the repository export;
- environment-specific Watson instance and flow identifiers were replaced with placeholders;
- the embedded API keys should be rotated before the next production promotion.
